
# NOOR VOYAGES

## Présentation du projet

NOOR VOYAGES est un site web consacré à l'organisation de voyages spirituels à La Mecque.

Il permet aux visiteurs de découvrir différentes formules de pèlerinage Hajj et Omra, de comprendre les étapes du voyage et de contacter l'agence.

## Technologies utilisées

- HTML5
- CSS3

## Fonctionnalités

- Page d'accueil
- Menu de navigation
- Présentation des offres de voyage
- Explication des étapes du pèlerinage
- Présentation de l'agence
- Formulaire de demande de devis
- Affichage adapté aux mobiles
